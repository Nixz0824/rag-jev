FALLBACK · 退回确定性流程

没有 key、预算用尽或调用失败：链路照常回答，降级写进 trace 与 jev_phases，不静默。

边界

只回答国服公告里的英雄、装备与系统数值改动；皮肤、云顶、模式机制不在收录范围。 公告只记录改动，因此「最近一次调整」不等于「当前数值」。公告原文只保存在本地，不随仓库发布。

本项目

本地优先：检索与两个 Qwen GGUF 都跑在本机，只有 Jev 需要外部 API key；没有 key 时自动退回纯检索排序， 语义补全与分层路由记 fallback，并在轨迹里标注。
